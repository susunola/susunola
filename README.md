What should be automated on Tencent Cloud is written so someone else can run it. Certificates renew themselves, baselines can scan and fix, and browser tools stay on the machine by default. Interfaces are bilingual. Secrets stay in the Keychain.

<br>

### 01 &nbsp; Control plane

[ansible-collection-tencentcloud](https://github.com/susunola/ansible-collection-tencentcloud)  
Ansible collection for Tencent Cloud resources. Alongside it: [Landing Zone](https://github.com/susunola/tencentcloud-landingzone), [GxP landing zone](https://github.com/susunola/gxp-landing-zone-tencentcloud), [Sentinel policies](https://github.com/susunola/tencentcloud-sentinel-policies), and [organization SCP examples](https://github.com/susunola/tencentcloud-service-control-policy-examples).

### 02 &nbsp; Certificates

[wecert](https://github.com/susunola/wecert)  
One binary, one SQLite file. DNS-01 via DNSPod, Tencent Cloud DNS, Cloudflare, or Route 53. Rebinds to CLB / CDN without dropping traffic.

### 03 &nbsp; Baselines

[ohbs-image](https://github.com/susunola/ohbs-image) · [ohbs-host](https://github.com/susunola/ohbs-host) · [ohbs-cloud](https://github.com/susunola/ohbs-cloud)  
Golden images, hosts, and cloud. CIS / GxP. Scan, remediate, report.

### 04 &nbsp; On the machine

[wescreen](https://github.com/susunola/wescreen) — Edge screen recorder. The timeline stays local.  
[lighttab](https://github.com/susunola/lighttab) — new tab. Lunar calendar, search, to-dos. Sync is optional.  
[WeSwitch](https://github.com/susunola/WeSwitch) — switch Codex models on macOS. Preview, then backup. Keys live in the Keychain.  
[TravelTime](https://github.com/susunola/TravelTime) — menu-bar time zones, and a one-click system time-zone switch.
